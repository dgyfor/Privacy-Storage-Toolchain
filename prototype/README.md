# prototype/ — 历史原型

## 映射盘.html

**定位：** 台账工具原型。加密并上传云盘之后，手动回来补记"哪个文件放在了哪个云盘"。

**为什么放这里：**
项目早期没有索引系统，只能靠手动录入记住文件与云盘位置的对应关系。后来 `encrypt_new.sh` + `setcloud` + `index.jsonl` 实现了自动索引，这份工具的功能被系统覆盖。

**保留理由：**
1. 答辩时作为需求演进证据 —— 先做手动台账验证需求，再设计自动化索引
2. UI 交互（树形结构、映射向导、长按菜单、搜索排序）可作为后续前端设计的参考

**跟主线的区别：**

| | prototype/映射盘.html | mapping-spa/index.html |
|---|---|---|
| 数据源 | localStorage，手动录入 | index.jsonl + encrypted_index.txt |
| 用途 | 编辑台账（增删改） | 只读展示真实加密索引 |
| 时代 | 早期，无索引系统 | 当前，索引闭环之后 |

**不要改动它。** 作为历史存档保留，是开发过程证据。
